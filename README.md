🚀 Project Web (Quản lý / Tour / Website)
📌 Giới thiệu

Đây là project website được xây dựng nhằm mục đích:

Quản lý dữ liệu (tour / user / contact / ...)
Thực hành lập trình web (PHP / MySQL / HTML / CSS / JS)
🛠️ Công nghệ sử dụng
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: PHP
Database: MySQL
Server: XAMPP
⚙️ Cài đặt & chạy project
1. Clone repo
git clone <link-repo>
2. Copy vào thư mục XAMPP
htdocs/
3. Import database
Mở phpMyAdmin
Import file: project.sql
4. Chạy project
http://localhost/project
